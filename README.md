# Baybayin OCR Dataset

A dataset for training custom **Tesseract LSTM OCR** models for the Baybayin script.

---

## Overview

This repository contains a Baybayin OCR training dataset developed to support research and development in **Optical Character Recognition (OCR)** for the Baybayin script. It was created as part of my undergraduate study, **"Baybayin Natin: A Mobile-based Transliteration App Using Tesseract OCR (2026)."**

The repository includes synthetic Baybayin character and word images generated from multiple Baybayin fonts, handwritten Baybayin character images, synthetic handwritten Baybayin word images, OCR training annotations, and dataset metadata. Unlike a typical image dataset, it also contains Tesseract training files such as `.tif`, `.box`, and `.gt.txt`, which are used in the training pipeline for custom **Tesseract LSTM OCR** models.

The dataset is intended to facilitate the training, evaluation, and benchmarking of Baybayin OCR systems and to support future research in OCR, computer vision, machine learning, and the digital preservation of the Baybayin writing system.

---

## Dataset Contents

The repository contains both **character-level** and **word-level** datasets from multiple Baybayin fonts, along with handwritten Baybayin samples and OCR annotation files required for Tesseract training.

Depending on the dataset subset, files may include:

| File      | Description                                        |
| --------- | -------------------------------------------------- |
| `.tif`    | TIFF images used for Tesseract LSTM training       |
| `.box`    | Character-level bounding box annotations           |
| `.gt.txt` | Ground-truth transcription files used by Tesseract |

The dataset is organized into separate character and word directories grouped according to their font or data source.

## How the Dataset Was Created

### Synthetic Dataset

The synthetic dataset was generated by rendering Baybayin text using several publicly available Baybayin fonts.

The rendered text was then processed into OCR training samples consisting of:

* TIFF (`.tif`) training images
* Character bounding box (`.box`) files
* Ground-truth transcription (`.gt.txt`) files

These files follow the format required by the **Tesseract LSTM training pipeline**, making the repository suitable for training or extending custom Baybayin OCR models.

### Synthetic Handwritten Words

Synthetic handwritten Baybayin word images were generated by combining handwritten Baybayin character images obtained from the **Apache 2.0 licensed Baybayin Character Dataset**.
